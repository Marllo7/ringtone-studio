# 🔔 Ringtone Studio

Веб-приложение для музыки и создания рингтонов: открываешь папку с песнями, выбираешь трек, выделяешь кусок на волне — и сохраняешь готовый файл прямо в телефон.

Работает в браузере (Chrome на Android / ПК, Safari на iPhone) по ссылке, устанавливается как приложение. Никаких серверов и CDN — весь код локальный, поэтому сайт открывается без VPN.

## Возможности

- **Музыка по папкам и плейлистам** — открывается папка с телефона или SD-карты, внутри — навигация по подпапкам с хлебными крошками
- **Плеер** — внизу панель с обложкой из тегов, управлением с локскрина телефона, перемешиванием и повтором
- **Обрезка на волне** — выделение пальцем, ручки начала/конца, точная подстройка ±0,01 с, зум, мини-карта дорожки
- **🎯 «Громкое место»** — автоматически находит самый громкий фрагмент (припев) нужной длины
- **Плавный старт/финиш** (фейды) и регулировка громкости без искажений
- **Плейлисты внутри приложения** + импорт/экспорт M3U — хранятся между запусками
- **Теги и названия** — читает ID3 (название, исполнитель, обложка), сортировка и поиск даже по большой библиотеке
- **Сохранение рингтонов**: скачивание в «Загрузки», «Поделиться» (на Android — в «Файлы», в том числе на SD-карту), на ПК — запись в любую папку/диск. Рингтоны остаются в приложении
- **MP3 без перекодирования в облаке** — кодирование идёт прямо в браузере (lamejs), качество до 320 кбит/с

Ограничения браузера (честно):
- Браузер не может сам назначить файл системным рингтоном — файл скачивается/шарится, а назначается в настройках телефона. Для iPhone в приложении есть короткая подсказка по кнопке «?» (на Android всё стандартно, подсказка не показывается).
- Список файлов музыки браузер не хранит между запусками на телефоне — папку нужно открыть заново (это один тап). Плейлисты и рингтоны хранятся постоянно.

## Запуск локально

Файлы открываются только через HTTP (ES-модули). Из папки проекта:

```
python3 -m http.server 8000
```

Открыть http://localhost:8000

## Проверка

Модульные тесты чистой логики (имена треков, волна, теги, M3U, обрезка, MP3-кодирование, иконки, целостность ресурсов):

```
node tests/unit.mjs
```

## Публикация на GitHub Pages (открывается без VPN)

1. Создать репозиторий на GitHub (например, `ringtone-studio`), **публичный**.
2. Загрузить все файлы проекта:

   ```
   cd "Ringtone Studio"
   git init -b main
   git add .
   git commit -m "Ringtone Studio"
   git remote add origin https://github.com/ВАШ_ЛОГИН/ringtone-studio.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Source: GitHub Actions** (деплой уже настроен файлом `.github/workflows/deploy.yml`).
4. Через минуту сайт доступен: `https://ВАШ_ЛОГИН.github.io/ringtone-studio/`

Проверить, что Pages включился: вкладка **Actions** — workflow «Deploy to GitHub Pages» должен быть зелёным.

## Как пользоваться (для телефона)

1. Открыть ссылку в Chrome → меню (⋮) → **«Установить приложение»** (или «Добавить на главный экран»).
2. Вкладка **«Музыка» → «Открыть папку»** — выбрать папку с музыкой (можно на SD-карте: в выборе папки видно оба хранилища). Песни появятся списком: с названиями из тегов, поиском, папками и плейлистами.
3. У нужной песни нажать **⋮ → «Сделать рингтон»**. В редакторе выделить кусок пальцем, послушать, либо нажать **«Громкое место»**.
4. **«Создать рингтон»** → файл скачается в «Загрузки» и сохранится во вкладке «Рингтоны».
5. На iPhone поставить рингтон можно через GarageBand — короткая инструкция по кнопке **«?»** в шапке.

## Состав проекта

```
index.html            — каркас приложения (единственная страница)
manifest.webmanifest  — PWA-манифест (установка на главный экран)
sw.js                 — service worker (кеш приложения)
css/styles.css        — стили (тёмная тема, mobile-first)
js/
  app.js              — сборка: вкладки, помощь, установка, обновления
  icons.js            — набор SVG-иконок приложения
  ui.js               — модалки, шторки, меню, тосты
  db.js               — IndexedDB (плейлисты, рингтоны, папки)
  engine.js           — аудио-ядро: декодирование, волна, обрезка, громкое место
  id3.js              — теги ID3v2 + парсер M3U
  library.js          — библиотека: источники, папки, плейлисты, поиск
  player.js           — плеер с панелью и MediaSession
  editor.js           — редактор волны и сохранение рингтонов
  ringtones.js        — вкладка рингтонов
  export.js           — MP3-воркер, скачивание, share, запись в папку
  mp3-worker.js       — кодирование MP3 в фоне (lamejs)
lib/lame.min.js       — MP3-кодировщик (MIT, локальная копия без CDN)
icons/                — иконки приложения
tests/unit.mjs        — модульные тесты (node tests/unit.mjs)
```

## Технологии

Vanilla JS без сборки и зависимостей, Web Audio API, Canvas, IndexedDB, File System Access API (на ПК), Web Share API, Media Session API, PWA. Кодировщик MP3 — [lamejs](https://github.com/zhuker/lamejs) (MIT, встроен локально).
